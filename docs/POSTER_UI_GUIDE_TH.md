# คู่มือหน้าจอ Retinova สำหรับโปสเตอร์และการสาธิต

## สิ่งที่ถอดแบบจากภาพอ้างอิง

หน้าเว็บยึดโครงเดียวกับภาพตัวอย่างทั้งหกภาพ ได้แก่ sidebar ด้านซ้าย, topbar, hero หน้าแรก, พื้นที่อัปโหลดสองคอลัมน์, ผลวิเคราะห์พร้อม Grad-CAM, กราฟผลย้อนหลัง และหน้าความรู้เรื่องจอประสาทตา

ชื่อแบรนด์ใช้ **Retinova** ตามชื่อโครงการปัจจุบัน แม้ภาพอ้างอิงเดิมจะแสดง VisionCare AI

## การจับคู่หน้าจอ

1. **Home** — แนะนำระบบ ปุ่มเริ่มวิเคราะห์ ภาพ fundus ตัวอย่าง และสถานะที่บอกว่าผลจริงยังไม่มี
2. **Analyze ก่อนเลือกภาพ** — เปิดกล้องโทรศัพท์หรือเลือกไฟล์ พร้อมอธิบายชนิดภาพ แหล่งภาพ และการจัดเก็บ
3. **Analyze หลัง local inference** — แสดงคลาสที่โมเดลทำนาย ความน่าจะเป็น สามอันดับแรก provenance และ Grad-CAM จริง
4. **History** — แสดงกราฟและรายการจากผล local model ที่เกิดในแท็บนี้เท่านั้น
5. **Eye Health** — แสดงตัวอย่างกายวิภาค fundus และแปดกลุ่ม label ที่ใช้ศึกษา
6. **AI Advice** — แสดง metric ที่วัดจริง วิธีประเมิน และข้อจำกัดของ baseline
7. **Settings** — อธิบายภาษา โหมดสาธิต และความเป็นส่วนตัว

## ส่วนที่ตั้งใจไม่คัดลอกเป็นข้อมูลจริง

- ไม่ใช้ตัวเลข 48 เป็นคะแนนสุขภาพตา
- ไม่ใช้ confidence 99% จากภาพตัวอย่าง
- ไม่สร้างจุดโรคหรือ heatmap ตกแต่ง
- ไม่สร้างเส้นกราฟย้อนหลังหรือประวัติผู้ป่วยตัวอย่าง

ตำแหน่งเดิมถูกแทนด้วย empty state หรือผลจากโมเดลจริง เพื่อให้ภาพโปสเตอร์อธิบายได้ตรงกับสิ่งที่กรรมการทดลองบนเว็บไซต์

## วิธีถ่ายภาพสำหรับโปสเตอร์

1. เปิดเว็บไซต์และเลือก **เข้าชมแบบผู้เยี่ยมชม**
2. ตั้งหน้าต่างเบราว์เซอร์เป็นอัตราส่วนประมาณ `960 × 514` เพื่อให้สัดส่วนตรงภาพอ้างอิง
3. เลือกหน้า Home, Analyze, History หรือ Eye Health จาก sidebar
4. ซ่อน bookmark bar และส่วนขยายของเบราว์เซอร์ก่อนจับภาพ
5. สำหรับภาพผล AI จริง ให้เปิด local model server วิเคราะห์ภาพ fundus ที่เหมาะสม แล้วจึงจับหน้าผลและ Grad-CAM
6. ใต้ภาพในโปสเตอร์ควรใส่คำว่า “ต้นแบบเพื่อการวิจัย ไม่ใช่การวินิจฉัย”

## วิธีสาธิตให้กรรมการ

- บน GitHub Pages: ทดลอง login แบบผู้เยี่ยมชม, เปิดกล้อง, ถ่ายภาพ, เลือกไฟล์, ตรวจชนิด/ขนาด/ความละเอียด และอ่านหลักฐานได้
- บน local model server: เพิ่มการทำนายด้วย EfficientNet-B0 และ Grad-CAM จริง
- กล้องโทรศัพท์เปล่าถ่ายได้เฉพาะตาภายนอก จึงไม่ส่งเข้าโมเดล เว้นแต่ยืนยันว่าใช้ชุดถ่าย fundus/เลนส์ที่เหมาะสม
- History อยู่ในหน่วยความจำของแท็บและหายเมื่อรีเฟรชหรือปิดแท็บ
